What's inside (v0.1: 8 skills)

verify-before-done Stop hook free

Detects your real test/typecheck/lint commands, runs them, and writes a receipt tied to the exact working tree. Claims like “done”, “fixed” or “all tests pass” are blocked without a fresh passing receipt. Editing after verifying invalidates it.

test-integrity free

Catches .skip/.only, deleted assertions and test files, changed expectations, tautologies, || true and loosened test config. A weakened test also blocks the “done” claim.

fail-loud free

Finds empty catches, log-and-continue, catches returning mock/sample/empty data, .catch(() => {}), except: pass. Diff mode checks only what the agent just wrote.

destructive-guard PreToolUse free

Blocks prisma migrate reset, db push --accept-data-loss, drizzle-kit push --force, DROP/TRUNCATE, reset --hard, force-push and rm -rf outside build dirs. Normal dev commands pass.

migration-safety full kit

Reviews new SQL migrations: DROP COLUMN, NOT NULL without default, unscoped UPDATE/DELETE, renames, unique indexes on live tables, and edits to already-applied migrations. Suggests expand → migrate → contract.

secret-shield PreToolUse free

Stops reading .env/key files, env dumps and echoing tokens. Scans the diff or repo for Stripe/OpenAI/AWS/GitHub keys and DB URLs, with values redacted in output.

dep-verify PreToolUse full kit

Before any npm/pnpm/yarn/bun/pip install, it checks the package exists, isn't brand-new or unused, and isn't a near-miss of a popular name. Nonexistent packages are blocked; suspicious ones go to you.

context-pack full kit

Fingerprints your repo (stack, exact commands, layout, Prisma models, routes, env var names) and writes one AGENTS.md, with CLAUDE.md and Cursor rule adapters. --check catches drift.

Plain Node ≥18, zero dependencies, nothing phones home (dep-verify only queries the public npm/PyPI registries). Works in Claude Code via hooks and in Cursor via rules plus the same scripts. CI-friendly exit codes.

FAQ

Isn't this just a CLAUDE.md I could write myself?

The rules part, yes, and the generated AGENTS.md is yours to edit. The value is enforcement: hooks block the action itself, and deterministic scanners don't “forget” instructions halfway through a long session.

Will it slow my agent down?

Each guard hook is a small Node process: about 85 ms per call in our measurements, mostly Node startup. dep-verify makes two registry requests only when installing a package. verify-before-done only adds the cost of running your own test suite, which the agent should be doing anyway.

Does it work with Cursor?

Yes, via an always-apply Cursor rule plus the same Node scripts run from the terminal or CI. Automatic blocking hooks are currently Claude Code-only.

False positives?

Some, by design (e.g. it asks before installing a package with <500 weekly downloads). Every rule is readable plain JavaScript; tune or delete what you don't want.

Does it send my code anywhere?

No. Nothing leaves your machine except package-name lookups to the public npm/PyPI registries.
